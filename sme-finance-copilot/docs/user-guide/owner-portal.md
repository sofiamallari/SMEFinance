# SME Owner Portal

Current implemented guide · 15 October 2026.

## Purpose

Run the merchant workflow from financial recording through authorized Bank review.

## Access and prerequisites

An SME Owner account assigned to the selected business. See the single [permission reference](../technical/security-permissions.md).

## Navigation

Use the Owner sidebar and the merchant selector in the header.

## Step-by-step instructions

1. Select the correct merchant before reviewing or entering data.
2. Delegate operational access to assigned Staff if needed.
3. Record transactions or import POS reports; review history and data-quality findings.
4. Review Dashboard, Cash Flow and Business Growth; use AI guidance or a hypothetical stress test if available.
5. Explore Financing, prepare an application, explicitly choose the Bank, grant the required authorization and confirm submission.
6. Read Bank feedback and revoke financial-data authorization when it is no longer needed.

## Understanding results and statuses

Dashboard reports, forecast estimates, maturity assessment and financing requests are distinct views; none independently proves cash availability or credit approval.

## Common errors and troubleshooting

A missing module or denied request can mean merchant assignment, account status or permissions need review. Change merchant explicitly; do not put another merchant ID in a chat request.

## Important limitations

CNY is the active demo currency. Payments and Bank outcomes are simulated. Owners delegate existing Staff; System Admin provisions accounts/memberships.
