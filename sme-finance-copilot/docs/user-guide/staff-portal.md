# SME Staff Portal

Current implemented guide · 15 October 2026.

## Purpose

Perform operational work explicitly delegated for a business.

## Access and prerequisites

An active SME Staff account, merchant membership and the required individual grants. The seeded Staff account initially has no grants.

## Navigation

Only delegated Owner-workspace modules appear in the sidebar.

## Step-by-step instructions

1. Ask the Owner to confirm your merchant assignment and required task permissions.
2. Sign in; select the permitted merchant.
3. Use Single Transaction or Bulk POS Import only if those actions are delegated.
4. Review only the dashboards, histories, forecasts or drafts permitted for that merchant.
5. After the Owner changes your grants, sign in again because the existing session is revoked.

## Understanding results and statuses

Membership alone does not grant operations. A delegated financing draft is not permission to submit it.

## Common errors and troubleshooting

An empty sidebar can be expected when no grants exist. Ask the Owner to review delegation; ask System Admin for missing account membership.

## Important limitations

Staff cannot submit financing applications, grant Bank access, manage platform security or delegate permissions. Backend restrictions apply even if a URL is typed directly.
