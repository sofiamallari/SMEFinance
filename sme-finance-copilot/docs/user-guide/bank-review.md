# Bank Financing Applications and Simulated Review

Current implemented guide · 16 October 2026.

## Purpose

Record and communicate scoped Bank review feedback.

## Access and prerequisites

Bank account receiving the request, live role permission, assignment, and active applications-category consent. Other financial data independently requires its category consent.

## Navigation

Bank → Financing Applications → View Details → Request Details / Financial Review / Bank Review / History.

## Step-by-step instructions

1. Find a request explicitly routed to your Bank.
2. Review request metadata and available authorized financial evidence.
3. In Bank Review choose Reviewed, More Information Needed or Ready for Further Assessment.
4. Provide notes; a note is required for More Information Needed.
5. Save the review and inspect the appended History entry.
6. Owner opens Financing → Applications → View Application to see feedback.

## Understanding results and statuses

A review appends history and an audit event without changing the submission status, which stays Submitted for Review. Banks record reviews only. The app does not approve, reject or disburse financing, and it does not simulate underwriting; any credit decision happens outside the app. Applications or reviews saved by an older version as approved or rejected are shown as **Review Closed**. Correct recipient identity and active applications consent remain required.

## Common errors and troubleshooting

An inaccessible request may belong to another Bank or an inactive merchant. Missing sections can reflect category-limited consent. Revoked/expired applications consent blocks request access and new reviews even if the recipient routing remains stored.

## Important limitations

Only the three review outcomes are supported; there is no approval or rejection. Prior downloads cannot be recalled; review notes are not underwriting decisions. Existing CSV financial export is supported; PDF/XLSX/email export is not.
