# Permissions and delegation quick entry

System Admin provisions accounts and bounded policy. Owner opens `/owner/users` to delegate only necessary actions to existing Staff in its merchant; Staff signs in again. Owner separately opens `/consents` to authorize/revoke an active scoped Bank. Bank membership or application submission never grants financial access automatically.

The [dedicated permissions reference](../SECURITY_PERMISSIONS.md) is the single source for the role/module matrix, aliases/migration, delegation, categories and restrictions. See [User Management](3%20README_User_Management.md) for UI instructions and [Bank Authorization](11%20README_Financing_Consent_and_Recipients.md) for the recipient workflow. Do not maintain a second local permission matrix in this quick guide.
