# Solution overview

SME Finance Copilot combines synthetic CNY merchant records, canonical POS/manual transaction management, sandbox digital collections, historical dashboards, weekday cash-flow forecasting, six-stage business maturity assessment, indicative financing/RBF and a consent-controlled Bank review workflow. The Owner assistant provides permission-aware financial reads/application guidance and optional hypothetical operating stress tests.

The POC demonstrates a trustworthy boundary between recording data, explaining evidence, exploring scenarios and taking explicitly confirmed sandbox actions. It does not connect real payment rails, grant credit, disburse loans or certify financial statements.

Four roles have separate duties. Owner authorizes individual Bank categories and routes a selected application; Bank records only simulated review feedback. Admin manages identities/configuration without automatic financial authority. Staff need individual merchant grants. These are implemented POC boundaries, with production gaps disclosed in [self-assessment](security-self-assessment.md).
