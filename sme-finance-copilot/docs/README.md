## Maintenance rules

When a module changes, update its user guide and affected technical/operations reference together. Keep permission rules only in the canonical security document. Keep provisional parameters separate from business approval. Link dated evidence with explicit scope; never describe skipped tests/provider calls as passed. Preserve older reports with a historical banner and canonical cross-reference. Word/PDF snapshots are not silently updated by Markdown maintenance.
