How Metrics Are Calculated
  • Parsed Rows = Eligible + Exact Duplicates + Invalid
  • Valid Row Rate = (Eligible + Exact Duplicates) / Parsed Rows
  • Invalid Row Rate = Invalid / Parsed Rows
  • Unresolved Alerts = Open + Acknowledged

Checks run during existing foreground validation, commit, recovery and expiration requests. No continuous background monitoring. N/A means no parsed rows for the denominator.
